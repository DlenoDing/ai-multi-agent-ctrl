# 第三十轮管理界面与 Agent 操作闭环复验

## 复验范围

- 项目管理与组织管理中 AI 智能体相关页面的职责边界。
- 任务组、执行监控、人工审核等页面在没有在线 agent 时给出的处置出口。
- Agent 注册、刷新自检、节点治理三类操作是否都能指向真实界面动作。
- 行为门、验证脚本、Docker 启动和浏览器走查是否能覆盖本轮改动。

## 发现的问题

前几轮已经把常规 agent 注册入口收敛到「项目管理」→「AI 智能体」→「注册 agent」，并在项目级和组织级节点操作里补齐「刷新自检」。继续从普通中文项目管理员视角推演后，仍发现一个文字级但会影响操作路径的残留问题：

- 任务组页、执行监控页和人工审核页的“没有任何在线的 agent 节点”提示仍会通过通用函数输出“接入或恢复节点”。
- “接入或恢复节点”不是当前界面上的真实按钮，也没有区分“一个节点都没有”和“已有节点离线或自检异常”。
- 对已有节点异常的场景，项目 agent 管理员现在可以在项目「AI 智能体」页对节点点「刷新自检」，但旧提示更强调找组织管理员，容易让项目负责人以为自己没有处置入口。
- 对需要强制吊销、立即切断、跨项目治理的场景，组织页仍然是正确出口，不能把全部动作都挪到项目页。

## 优化方案

1. 保留现有系统设计：服务端集中托管 MCP 与 Skill，同步给轻量 agent；agent 通过注册脚本拿 node token 后长轮询控制命令、实时回写心跳和事件。
2. 将“无在线 agent”的管理出口拆成真实操作路径：
   - 没有注册节点：进入当前项目「AI 智能体」→「注册 agent」签发一次性加入令牌并复制服务端安装脚本。
   - 已有节点离线、自检异常或执行器刚修好：有项目 agent 管理权限的人进入当前项目「AI 智能体」点「刷新自检」。
   - 需要跨项目治理、吊销或立即切断：组织管理员进入「组织管理」→「AI 智能体」处理。
3. 任务组、执行监控、人工审核共用同一出口文案，减少重复长提示并提高缓存命中。
4. 收紧行为门：无在线 agent 提示必须出现项目注册路径、刷新自检路径，且不得再出现“接入或恢复节点”这种不可点击的泛化动作。

## 实施记录

- 已将运行界面共用的 agent 节点处置出口改成三段真实路径：
  - 当前项目没有注册节点时，指向「项目管理」→「AI 智能体」→「注册 agent」签发加入令牌并获取服务端安装脚本。
  - 当前项目已有节点但全部离线、降级或执行器刚修好时，指向项目「AI 智能体」节点行的「刷新自检」。
  - 需要跨项目治理、吊销或立即切断时，指向组织「AI 智能体」。
- 已同步任务组页、执行监控页、人工审核页和在制品扩容提示使用新出口。
- 已补充行为门，覆盖：
  - 监控页已有节点全掉线时必须显示「刷新自检」。
  - 监控页已有节点全掉线时必须提示先恢复目标 agent 主机/进程心跳，避免误导为单点「刷新自检」即可恢复离线节点。
  - 监控页一个节点都没注册时必须显示「注册 agent」和加入令牌。
  - 任务组页已有节点全掉线时必须显示「刷新自检」。
  - 任务组页已有节点全掉线时必须提示先恢复目标 agent 主机/进程心跳。
  - 任务组页一个节点都没注册时必须显示「注册 agent」和加入令牌。
  - 人工审核页等待 AI 再分析但无在线节点时必须显示「刷新自检」且给出人工定稿/打回出口。
  - 组织概览无节点时不得写成“先接入节点”，必须表达为新增 agent 先进入目标项目注册。
  - 在制品扩容提示必须同时显示「注册 agent」「刷新自检」和「准入」，且不得出现“接入或恢复节点”。
- 外部互审指出两处继续修正：
  - 组织概览的 Agent 节点卡片仍写“需要执行任务前先接入节点”，已改为“新增 agent 先进入目标项目注册”。
  - 已有节点离线时不能暗示点击「刷新自检」即可恢复，已改为“先恢复目标 agent 主机/进程心跳；执行器或能力修好后再点刷新自检”。
  - 执行监控刚装空态中的“接一台节点 / 接一台执行节点”已改成“签发加入令牌并在 agent 主机运行安装命令注册一台节点”。

## 最终复验补充

完整 `mutation-gate` 第一次复跑时发现产品逻辑已稳定，但四个守卫登记存在旧预期或假绿风险：

- “有项目时两个入口必须还在”的预期文案仍是旧失败串，已改为当前真实会报红的“项目页必须保留注册表单”。
- 系统管理员刚装完监控页的空态指路只被泛化校验覆盖，已新增横幅级正向断言，必须指向「项目管理」→「AI 智能体」→「注册 agent」，且不得回退到旧的「项目设置」→「智能体接入」。
- “到 agent 页”这种未加书名号的英文裸页名原变异没有打到用户可见文案，已改成直接变异真实阻塞出口文案。
- `verifyGuidanceNamesRealPages` 现在单独统计「X」处/「X」按钮式控件指路，避免只剩“点「X」”时仍假绿。
- `verifyFirstScreenPointsAtRealPlaces` 现在显式拒绝首屏旧入口「项目设置」→「智能体接入」，避免旧入口名字碰巧仍在其它页面而被误判为可用。
