# 中文管理控制台流程清晰度终态审计

日期：2026-09-06  
状态：实施中

## 本轮审计方法

不以“已经有 Tab 或菜单”为完成标准，而以普通管理者能否从稳定入口连续完成一个对象的列表、创建、详情、授权、监控和处置为标准。逐项对照 `navigation.js` 的可见入口、`workspaces.js` 的面板所有权、真实账号权限和浏览器页面。

## 已确认边界

- 系统管理员只进入系统治理空间，只管理组织、初始组织管理员、配额、启停和平台能力。
- 组织管理员管理组织子账户、组织项目目录、项目／任务组授权、组织共享 Agent 档案和共享运行节点。
- 项目空间同时展示当前项目 Agent 与本组织共享 Agent，任务组调度已通过真实 e2e 验证两类候选的作用域和跨组织排除。
- 项目、任务组和任务均有独立进度；任务列表按时间倒序，任务详情包含执行尝试、Agent、角色、模型、规则、事件和 Git 结果。
- 项目级与任务组级监控共用同一执行数据链，任务组范围进入页头、地址、查询和权限判断。

## 第一项剩余问题：成员授权仍是复合页面

`项目成员` pane 同时拥有“项目成员列表”和“项目成员授权”；`任务组权限` pane 同时拥有“任务组权限列表”和“任务组权限授权”。这仍是把查阅与创建表单放在一页，只是外面换了菜单名。

终态拆分为四个稳定入口：

1. 项目成员：只看成员、角色影响和成员详情。
2. 添加项目成员：只选择组织账号与项目角色并提交。
3. 任务组权限：只看按任务组分配的角色和状态。
4. 授予任务组权限：只选择任务组、账号和任务组角色并提交。

无 `project:grant` 权限的账号不显示两个授权入口；列表和详情仍可按其读取权限访问。四个入口使用独立 `pane` 地址，列表页按钮直接进入创建页，不再在长页面内滚动定位表单。

## 后续检查面

- 逐页检查是否还存在“一个菜单同时承担列表与创建”或“默认先看说明再找到操作”的复合 pane。
- 真实走查项目负责人添加成员、授任务组权限、打开成员详情和撤销授权。
- 复查项目／任务组监控、人工审核、复核和独立指令的入口与对象范围。
- 继续拆分 `app.js` 中仍然过大的纯渲染模块，不改变服务端契约和实时执行链。
- 完成桌面、390px、全量验证、变异门、Docker 和外部只读复审。

## 第二项剩余问题：执行对象仍堆在“执行会话”

原“执行会话”页面同时渲染工作会话、Agent 派发、Worker Lane、模型选择和会话放置五类对象。它们的排障问题不同：会话回答是否持续、派发回答任务交给谁、Lane 回答载体复用、模型决策回答为何选这个模型、会话放置回答为何新建会话或使用子 Agent。

现拆为“工作会话、Agent 派发、执行载体、模型决策、会话放置”五个稳定入口；任务组范围进入后显示对应的任务组级标题。旧 `pane=runs` 地址自动迁移到“工作会话”，节点的“当前任务”入口直达“Agent 派发”。

## 第三项剩余问题：节点、命令和死信混在一起

原“节点控制”同时展示运行节点、控制命令 ACK 和死信队列。现拆为“运行节点、控制命令、死信队列”三个入口：先看节点健康和准入，再看控制命令是否送达／确认，重试超限才进入死信处置。旧 `pane=nodes` 地址自动迁移到“运行节点”。

## 第四项剩余问题：产出、质量与裁决混在一起

原“产出验收”同时展示 Git 检查点、质量门／测试证据和人工定稿记录。现拆为“检查点证据、质量门禁、人工定稿”三个入口；质量门待办和项目当前主操作直达“质量门禁”。旧 `pane=evidence` 地址自动迁移到“检查点证据”。

## 第五项剩余问题：放置与准入混在一起

会话放置决定使用新会话、已有会话或子 Agent；准入决策记录阶段门、容量和依赖为什么允许／拒绝执行。现拆为“会话放置”和“准入决策”两个入口，避免把执行载体选择误读成准入结论。

## 第六项剩余问题：三类人工处置混在一起

原“授权与复核”把权限请求、危险操作审批和评审发现混在同一页。现拆为“权限审批、操作审批、发现处置”：权限审批显示主体、权限和资源作用域；操作审批处理危险动作和阶段门；发现处置要求结论、状态与必要证据。待办红点和项目主操作按实际类别直达对应页面，多类别同时存在时进入待办汇总。旧 `pane=decisions` 地址迁移到“权限审批”。

## 第七项剩余问题：默认角色与 Skill 覆盖混在一起

项目默认角色决定任务组未指定时的角色回退；角色 Skill 定制改变项目／任务组的能力和约束。现拆为“默认角色”和“Skill 定制”两个项目治理入口，旧 `pane=roles` 地址迁移到“默认角色”。

## 第八项剩余问题：指令效率与共享定义混在一起

指令压缩指标用于观察 token、固定 envelope 和缓存命中；共享定义归属用于确定多子项目公共标准由谁定义、产出和裁决。现拆为“指令效率”和“共享定义”两个系统能力入口，旧 `pane=protocol` 地址迁移到“指令效率”。
