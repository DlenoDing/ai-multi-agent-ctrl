# Agent 档案与模型选择一致性复验

日期：2026-09-06  
状态：实施中

## 目标

确保组织级/项目级 Agent 档案不只是管理界面的静态记录，而是真正参与任务组派发时的 Agent 与模型选择；同时保持总控按任务内容、风险、阶段门和模型能力动态裁决，不引入固定 profile 表，也不把 Agent 模型偏好变成绕过任务上限的硬编码。

## 已确认能力

- 逻辑 Agent 档案与运行节点是两类对象：档案定义角色、Skill、模型偏好和信任分；节点负责注册、自检、领活、执行和实时回送。
- 组织级档案可供本组织项目复用；项目级档案优先服务当前项目。
- `agentForRole` 已按“当前项目同角色档案优先，组织同角色档案兜底”选择逻辑 Agent。
- 组织共享节点动态覆盖本组织项目，项目专属节点仅覆盖绑定项目；跨组织节点不会认领任务。
- 每次派发均显式记录实际模型、推理等级和简短 `modelDecision`，不使用固定模型 profile 表。

## 已确认问题

### P0：Agent 档案的默认模型不参与模型选择

`agentForRole` 只把 Agent ID 写入工作会话；`selectModel` 完全不读取选中 Agent 的 `model`。控制台允许创建项目级 Agent 并填写“默认模型”，列表也持续展示，但该值不会改变任何模型候选、模式或决策记录。

处理：

- 先按项目优先、组织兜底选择逻辑 Agent。
- `auto_best`、`auto_fast`、`cost_aware` 作为该 Agent 的默认选择模式；任务请求显式指定的模式仍优先。
- 实际模型 ID 作为软偏好进入评分，只在满足任务硬约束、模型档位和推理上限后加分，不能绕过总控裁决。
- 模型选择记录增加 `selectedAgentId`、`agentModelPreference` 和偏好评分，便于任务详情与监控解释为什么使用该模型。

### P1：旧运行态存在非标准模型偏好值

早期默认 Agent 使用 `balanced`、`deep`，当前创建表单和选择器只认 `auto_best`、`auto_fast`、`cost_aware` 或真实模型 ID。旧值在中文界面直接显示英文，同时无法映射到任何实际模型。

处理：运行态归一化时将旧默认别名迁移到等价的动态模式；用户明确填写的真实模型 ID 和未知自定义模型不擅自改写。

### P1：项目可调配角色缺少作用域汇总

表格逐行标出组织级/项目级，但在角色较多时无法快速判断当前项目有多少项目专属档案、多少组织共享档案、哪些角色缺少活动档案。

处理：在“可调配角色”顶部增加项目专属、组织共享、活动档案、覆盖角色四项汇总；保留完整明细与创建表单。

### P1：模型选择监控未显示对应 Agent 档案

任务详情能通过工作会话反查 Agent，模型选择记录却只显示角色、任务和模型。发生项目档案优先/组织档案兜底时，监控页无法直接解释选择来源。

处理：模型选择记录直接显示 Agent 档案和模型偏好；若没有匹配档案，明确显示“未绑定档案”，不伪造默认对象。

### P0：Agent 档案的 Skill 与信任分未参与选择

`roleSkillRef` 原先只在档案表中展示，任务契约仍按角色默认 Skill 解析；同一作用域有多个同角色 Agent 时则按数组顺序取第一个，`trustScore` 和 `capacity` 都不参与。项目/任务组特殊角色配置因而可能没有进入执行包。

处理：同层 Agent 先选 `ready`，再按信任分降序和稳定 ID 排序；项目级仍整体优先于组织级。选中档案的 `roleSkillRef` 作为基础 Skill，项目/任务组 overlay 继续按既有优先级叠加；模型选择记录、任务契约和工作会话绑定同一 Agent 与 Skill。

## 实施顺序

1. [已实现] 将逻辑 Agent 与模型偏好接入动态模型选择，并扩展决策 schema。
2. [已实现] 归一化旧默认 Agent 的非标准模型偏好。
3. [已实现] 增加项目可调配角色作用域汇总和模型选择监控列。
4. [已实现] 增加项目级优先、组织级兜底、模式映射、实际模型软偏好、硬约束不可绕过的合同测试。
5. 完成桌面/移动端浏览器走查、全量验证与 Claude 外部复审。

## 验收条件

- 项目级同角色 Agent 存在时，决策记录绑定项目级 Agent；否则绑定组织级 Agent。
- Agent 的动态模式会成为缺省 `selectionMode`，但派发请求显式值可以覆盖。
- 实际模型偏好只在候选合格后影响排序，不能选择超过任务模型/推理上限或不满足工具、上下文能力的模型。
- 模型选择记录和任务工作会话指向同一个逻辑 Agent。
- 项目 Agent 页能快速看清项目专属与组织共享档案构成。
- 全量验证和外部复审无未处理高风险问题。
