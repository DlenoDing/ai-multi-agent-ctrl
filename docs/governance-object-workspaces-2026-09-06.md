# 治理对象工作区与任务级人工控制复验

日期：2026-09-06  
状态：实施中

## 目标

把系统管理员、组织管理员和项目操作者的管理路径收敛为“先定位对象，再在对象上下文内完成操作”，并修正任务级人工指令在界面与运行语义之间不一致的问题。系统继续保持 AI-native：人只管理租户、权限、风险、审核和必要控制，任务拆解、模型选型、Agent 调配、执行与实时回送仍由总控和运行时完成。

## 本轮真实走查范围

- 系统管理员：组织列表、初始组织管理员、组织启停、四类配额。
- 组织管理员：创建子账户、项目创建、项目成员授权、任务组授权、组织级与项目级 Agent 入口。
- 项目操作者：任务详情、任务组监控、人工审核、人工指令。
- 跨账号：系统管理员退出后，以新组织的初始管理员首次登录并继续创建成员和项目。
- 代码链路：控制台表单 -> REST -> `createHumanDirective` -> 编排周期消费。

## 已确认问题

### P0：任务级“调整优先级”实际扩大到整个任务组

人工指令表单为“调整优先级”展示了目标任务字段，但提交处理只在“决策处置”时发送 `workItemId`；核心对象也只在“决策处置”时保存该字段。结果是操作者明确选择一个任务，编排器却会修改任务组内全部未完成任务。这是可复现的对象作用域错误。

处理：

- `adjust_priority`、`add_requirement`、`free_text` 和 `resolve_decision` 均可携带明确的 `workItemId`。
- 服务端校验任务必须属于目标任务组，不能接受悬空或跨组编号。
- 任务级补充要求只进入指定任务和该任务的派发上下文，不能污染同组其它任务。
- 任务详情进入人工指令时自动带入任务组与任务，不要求操作者再次查找编号。

### P1：功能栏目状态跨账号泄漏

功能栏目选择保存在单一 `aimac.workspaces` 键中。真实走查中，新组织管理员首次打开项目“成员权限”时继承了上一个账号的“授权说明”栏目，导致最常用的成员列表和授权入口被隐藏。

处理：栏目选择按账号隔离；切换账号后加载该账号自己的选择，新账号使用每个页面的第一主操作栏目。

### P1：系统组织管理缺少组织对象工作区

系统页已能展示初始管理员、组织状态和四类配额，也能重发未接受的邀请，但所有信息和操作都挤在宽表一行内。系统管理员无法先打开一个组织，再集中核对管理员登录状态、用量压力、启停影响和危险操作。

处理：组织列表只负责定位；新增独立组织详情工作区，集中展示组织身份、初始管理员、配额、风险和操作。列表保留摘要，不再承担全部治理表单。

### P1：组织成员管理缺少成员对象工作区

当前成员列表把账号能力、项目与任务组授权、邀请、停用和注销全部放在同一行。授权又需要进入权限矩阵，再跳到项目成员/任务组权限栏目，操作者会多次重新选择同一成员和项目。

处理：新增成员详情工作区；从成员列表打开后固定成员上下文，在同一页面展示账号状态、账号能力、项目角色、任务组角色和生命周期操作，并按所选项目直接提供项目角色与任务组角色表单。仍复用同一套服务端授权 API，不增加第二套权限模型。

### P2：任务详情跳转只保留任务组，不保留任务

任务详情已有“任务组监控 / 任务组审核 / 任务组指令”，但进入人工指令后只保留任务组，具体任务丢失。对于任务级补充要求、优先级和决策处置，操作者必须再次查找任务编号。

处理：任务详情增加任务上下文跳转；人工指令显示“任务组 / 具体任务”双层目标，流水也展示目标任务。

## 已有能力，不重复建设

- 系统管理和组织/项目管理已有独立管理空间与菜单，不重新合并。
- 仓库账号密码/API Key 为项目级密文配置，连接测试和 Agent 凭证下发已实现。
- 组织级 Agent 档案与共享节点、项目级 Agent 档案与专属节点已分层；任务组调度可使用两类资源。
- 项目进度、任务组进度、任务倒序列表、任务执行次数、角色、模型、推理、规则与实时回送已有专用视图。
- 项目与任务组监控、任务组级审核/控制/观察授权已有服务端资源判权。

## 验收条件

- 新账号不会看到其他账号上次选中的功能栏目。
- 系统管理员可从组织列表进入单个组织详情，且只能看到系统层应管理的组织、初始管理员、配额和启停操作。
- 组织管理员可从成员列表进入单个成员详情，不离开成员上下文即可核对并分配项目/任务组角色。
- 对任务 A 下达优先级或补充要求不会修改同组任务 B；跨组任务编号被明确拒绝。
- 从任务详情进入人工指令时，目标任务已选中且在流水中可见。
- 桌面与 390px 窄屏无横向页面溢出、按钮和文字不重叠。
- 全量验证、关键变异验证和外部复审均无未处置高风险问题。
