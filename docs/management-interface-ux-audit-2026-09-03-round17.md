# 管理界面第十七轮多角度复验与优化方案（2026-09-03）

## 复验范围

本轮继续按中文用户的管理习惯复验系统管理、组织管理、项目管理三类空间。重点不再只看页面是否能显示，而是看普通管理者能不能用最短路径完成“看状态、找问题、发操作、接入 agent、拿注册脚本”。

复验角度包括：

- 功能入口：Agent 节点查看、加入令牌、注册脚本、节点控制是否有清晰的一等入口。
- 中文管理习惯：项目负责人通常从项目维度管理执行资源，不应先理解组织级页面和项目设置页的混合关系。
- 页面分层：项目设置已经承载仓库、基线、默认角色、系统规则、业务规则和智能体接入，信息密度过高。
- 操作闭环：当项目没有在线 agent 时，概览页应直接指向“注册 agent”的页面，而不是只给文字说明。
- 性能边界：优先复用现有视图数据和接口，不新增高频请求、不新增实时订阅、不改变项目分片存储。

## 发现的问题

- 项目管理侧栏没有独立“AI 智能体”入口。项目负责人需要先进入“项目设置”，再在页面中部找到“智能体接入”，注册脚本来源不够直观。
- 项目设置页把配置类事项和运行资源接入混在一起。对中文后台用户来说，“仓库/规则配置”和“Agent 节点/加入令牌/注册脚本”属于不同管理对象。
- 项目概览已经提示“没有在线 agent 节点”，但提示只是长文本，缺少直接进入项目智能体管理的图形化入口。
- 组织级“AI 智能体”页有节点总览、操作看板、节点列表和加入令牌管理；项目级缺少对应的轻量视图，导致项目负责人无法按当前项目直接判断可用节点、异常节点、待用令牌和注册方式。

## 优化方案

- 在项目管理菜单中新增独立页面“AI 智能体”，放在“执行监控”和“项目设置”之间，承担项目级节点查看、节点控制、加入令牌与注册脚本获取。
- 新增项目级智能体页：
  - “项目智能体总览”：节点总数、在线节点、忙碌节点、当前任务、待用加入令牌、异常节点。
  - “接入与处置看板”：用图形化卡片把“注册新 agent”“查看节点”“定位异常”“查看运行任务”“查看待用令牌”分开。
  - “项目智能体节点”：只展示绑定当前项目的节点，保留暂停、取消、刷新等现有控制操作。
  - “注册 agent”：复用现有一次性加入令牌表单和弹窗，直接显示服务端生成的安装命令。
- 项目概览增加“AI 智能体”模块卡片，让“没有在线 agent”这类问题可以一跳到正确页面。
- 项目设置页保留轻量引导卡，不再把智能体接入作为主要配置段落，减少设置页的信息堆叠。
- 补充行为门，断言项目菜单必须包含“AI 智能体”、项目智能体页必须含注册入口与节点视图、项目概览必须提供 AI 智能体跳转。

## 验收要求

- 项目成员视角：侧栏能直接看到“AI 智能体”，点击后进入项目级节点与注册页。
- 项目概览：模块卡片中出现“AI 智能体”，能直接跳转到项目智能体页。
- 项目智能体页：首屏先是总览和图形化看板，再是节点列表和注册 agent 区域；空节点时明确告诉用户先签发加入令牌。
- 项目设置页：主要保持仓库、基线、默认角色、系统规则、业务规则，不再把 Agent 接入作为隐藏在设置页中的核心操作。
- 移动端：390px 宽度下项目菜单不横向溢出，项目智能体页没有页面级横向溢出。
- 工程验证：语法检查、diff 卫生、console-behaviour-gate、mutation-anchors、validate、docker:doctor 通过。

## 实施结果

- 已新增项目级“AI 智能体”菜单页，并接入项目视角的数据加载：`tasks` 视图提供任务组与派发，`runtime` 视图提供项目范围内的 agent 节点和加入令牌。
- 已新增“项目智能体总览”“项目智能体操作看板”“项目智能体节点”“注册 agent”四个清晰栏目，复用现有节点控制、一次性加入令牌和注册脚本弹窗能力。
- 已在项目概览增加“AI 智能体”模块卡片；当项目没有节点时，入口直接显示“注册 agent”，避免用户只看到长提示却不知道去哪里拿脚本。
- 已将项目设置页中的旧“智能体接入”表单替换为“AI 智能体”跳转引导，使设置页回归仓库、基线、默认角色和规则配置。
- 已补充行为门：项目菜单必须包含 AI 智能体用途说明，项目 AI 智能体页必须按总览、看板、节点、注册入口排序，项目概览必须提供 `proj-agents` 一跳入口。
- 真实浏览器项目成员视角：桌面 1280px 下项目概览有 AI 智能体模块卡片，项目侧栏有 AI 智能体菜单，新页面四个栏目顺序正确，项目设置页无旧“智能体接入”表单且保留 AI 智能体跳转，页面无横向溢出。
- 真实浏览器移动端 390px：项目菜单只显示短标题，AI 智能体页可见“签发一次性加入令牌”，无页面级横向溢出。
