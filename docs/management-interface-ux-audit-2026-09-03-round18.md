# 第十八轮管理界面与 Agent 操作链路复验

## 复验范围

本轮继续按中文管理用户的实际操作路径复验系统管理、组织管理、项目管理和项目内任务执行页面，重点检查：

- 系统管理、组织管理、项目管理是否仍有边界混杂。
- Agent 注册、查看、控制、脚本获取是否已经成为项目维度的一等入口。
- 页面是否先给现状和入口地图，再进入列表、表单和底层记录。
- 文字提示是否指向真实可见页面，避免用户照提示找不到入口。
- 优化是否只基于当前已加载视图聚合，避免额外轮询或新依赖，保持简单、稳定和高性能。

## 新发现的问题

上一轮已经新增项目级「AI 智能体」页面，但进一步从文档、阻塞提示和空状态提示反查，仍发现几类不一致：

- 文档入口残留旧路径。README、Agent Runtime 协议、总设计文档仍写「项目管理」→「项目设置」→「智能体接入」，与当前真实页面「项目管理」→「AI 智能体」→「注册 agent」不一致。
- 运行界面部分告警仍指向旧路径。无在线 agent、项目刚启动且没有执行记录等提示，仍要求用户去项目设置里找智能体接入。
- 行为门仍允许旧词通过。部分断言用「智能体接入或 AI 智能体」的宽松匹配，无法防止新代码再次退回旧入口。
- 项目级 Agent 页虽然已有总览、看板、节点和注册区，但缺少更明确的“注册步骤”图形化说明。普通用户第一次打开时仍需要读提示文字，才能知道一次性令牌、安装脚本、自动自检、远程 MCP 配置的顺序。
- 组织级 Agent 页的加入令牌管理更偏列表和表单，缺少一张说明“组织页管全组织节点，项目页负责按项目注册”的边界卡，容易与项目级入口混淆。

## 优化方案

- 全仓统一 Agent 注册入口为「项目管理」→「AI 智能体」→「注册 agent」。旧审计历史文档保留历史事实，不作为当前入口；README、协议、设计文档和运行界面提示必须改为新入口。
- 在项目级「AI 智能体」页增加“注册流程”图形化栏目，放在操作看板之后、节点列表之前。流程包含：选择项目、签发一次性加入令牌、复制服务端安装命令、Agent 自动注册自检并维护远程 MCP、回到节点列表确认在线。
- 在组织级「AI 智能体」页增加“管理边界”栏目，说明组织页负责全组织节点状态、控制和吊销；项目页负责某个项目的注册脚本与节点使用。
- 收紧行为门：断言所有当前运行提示必须出现「项目管理」→「AI 智能体」→「注册 agent」，并且不再把「项目设置」→「智能体接入」作为合格入口。
- 保持性能边界：新增栏目只使用当前页面已加载的 `agentRuntimeNodes`、`agentJoinTokens`、`agentDispatches`、`taskGroups` 和 `projects` 聚合，不新增接口、不新增轮询、不扩展服务端写路径。

## 预期验证

- `node --check` 覆盖前端脚本和行为门脚本。
- `npm run console-behaviour-gate` 确认页面顺序、入口文案和断言收紧。
- 真实浏览器桌面与窄屏走查：项目 Agent 页显示“总览 → 操作看板 → 注册流程 → 节点 → 注册 agent”，组织 Agent 页显示“总览 → 操作看板 → 管理边界 → 节点 → 加入令牌管理”。
- `npm run validate` 和 `npm run docker:doctor` 做全量回归。

## 实施结果

- 已新增项目级“Agent 注册流程”栏目，放在“项目智能体操作看板”之后、“项目智能体节点”之前，按 5 步展示：选择项目、签发令牌、复制脚本、自动自检、确认可用。
- 已新增组织级“智能体管理边界”栏目，明确组织页负责全组织节点状态、控制和吊销，项目页负责按项目签发一次性令牌、复制注册脚本和确认项目节点可用。
- 已统一当前有效文档和运行提示里的注册入口为「项目管理」→「AI 智能体」→「注册 agent」，并修正 README、Agent Runtime 协议、总设计文档、项目无节点提示、监控空状态提示、`agentctl --help` 和 `npm run init` 输出。
- 已将系统概览“账号与授权”卡片说明从“后台代签令牌”改为“系统账号、访问授权与服务账号边界”，避免把 Agent 注册继续理解成系统账号页职责。
- 已收紧行为门：项目 Agent 页必须出现“Agent 注册流程”；组织 Agent 页必须出现“智能体管理边界”；运行提示不得再指向「项目设置」→「智能体接入」。
- 真实浏览器桌面 1280px：项目 Agent 页面板顺序为“项目智能体总览 → 项目智能体操作看板 → Agent 注册流程 → 项目智能体节点 → 注册 agent”，远程 MCP 和注册脚本说明可见，无旧路径，无横向溢出。
- 真实浏览器移动端 390px：项目 Agent 页保留同样面板顺序，菜单只显示短标题，无页面级横向溢出。
- 组织级 Agent 页由行为门使用合成组织管理员视角覆盖，页面顺序要求已升级为“智能体运行总览 → 智能体接入操作看板 → 智能体管理边界 → 智能体节点 → 加入令牌管理”。
- `npm run init` 首屏已重新验证，agent 指引输出为进入目标项目后到「项目管理」→「AI 智能体」→「注册 agent」签发一次性入网命令。
