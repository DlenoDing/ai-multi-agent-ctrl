# 管理台功能与交互复验记录（2026-09-03）

## 范围

本次复验覆盖 AI Multi-Agent Ctrl 当前管理台的系统管理、组织管理、项目管理、任务组、人工审核、人工指令、执行监控、项目设置与登录入口。目标是按中文用户的管理习惯检查信息结构、操作路径、实时可读性和移动端可用性，并在不增加系统复杂度的前提下修正明显问题。

## 当前结构

- 系统管理：系统概览、组织管理、系统设置、账号与授权，并可切到当前项目进行排障和支撑。
- 用户管理：组织概览、成员管理、AI 智能体、项目管理，并进入项目视角处理任务组。
- 项目执行：项目概览、任务组、人工审核、人工指令、执行监控、项目设置。
- 核心闭环：总控创建任务组与工作项，派发给 agent 会话或节点，agent 经服务端实时上报事件、检查点和结果，监测与审核页面按任务组聚合展示。

## 视觉与交互走查结论

- 桌面端主流程可用，系统/组织/项目三层入口完整，任务组和执行监控能看到执行态、阻塞态、门禁态与回执信息。
- 页面文案整体已经中文化，但部分权限码会通过通用翻译函数直出英文枚举，并触发开发期告警。
- 手机宽度下侧边菜单换行成多行，占据过多首屏高度；顶栏项目选择和账户操作也会堆叠过高，影响查看任务状态。
- 执行监控中长任务组名称、仓库地址、派发编号等元信息在窄屏下容易把局部容器撑宽。
- 登录页和重新初始化提示偏工程化，中文用户读起来需要先理解实现细节；高危操作应先说明后果、范围和确认机制。

## 修正项

- 权限码补齐到中文字典，避免授权列表、徽标或通用渲染路径显示英文码。
- 移动端菜单改为单行横向滚动，顶栏和内容区域收紧，避免首屏被导航挤占。
- 元信息行在窄屏下改为纵向紧凑排列，并对长文本做 `overflow-wrap:anywhere`。
- 登录页改为“本地调试 / 生产不展示凭据 / 首次登录后设置密码”的短结构。
- 重新初始化提示改为高危操作清单，保留现有打字确认机制说明。

## 非目标

- 不改变任务调度、agent 注册、中心化 MCP、项目分片存储、实时事件链路等后端契约。
- 不新增 profile 表或固定模型档位表；模型选择仍由总控按任务内容显式写入 dispatch envelope。
- 不重做整体视觉系统；本轮只做能直接提升清晰度、稳定性和窄屏可用性的低风险修正。

## 复验标准

- 登录页、系统管理、组织管理、项目管理、任务组、执行监控和项目设置在桌面端无明显横向溢出。
- 390px 移动端无页面级横向溢出，导航不再换行占据多行。
- 常见权限码经 `t()` 或权限渲染路径均能显示中文。
- 静态语法检查、契约检查、全量校验与 Docker 启动体检通过。
