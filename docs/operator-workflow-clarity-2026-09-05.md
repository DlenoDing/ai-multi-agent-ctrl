# 管理对象与操作路径复查

基线：`3bece85`。本轮延续既有系统／组织／项目作用域、仓库凭据、共享 Agent、规则编辑器和任务工作台，不重复重建已验证的后端能力。目标是让对象、范围、状态和下一步操作在实际使用位置可见。

## 本轮确认的问题

| 问题 | 证据与影响 | 处理方向 |
| --- | --- | --- |
| 组织项目列表无法直接进入项目 | `renderOrgProjects` 的列表行只有归档，进入项目按钮在说明栏目中 | 项目名称可进入；每行提供成员、设置等明确入口，归档作为独立次要操作 |
| 概况重复且操作离对象太远 | 项目概况重复显示进度、状态，并展示七张大菜单卡片；任务组一览没有行级入口 | 单份项目摘要、紧凑状态入口，任务组行直达详情、任务和监控 |
| 创建按钮重复 | 工作区通用标题和列表标题可同时显示同一个创建按钮 | 通用工作区只在没有对象列表主操作时补按钮，确保单一主入口 |
| 成员授权没有保留对象 | 成员行“项目与任务组授权”只跳到全量矩阵；后续表单要重新选择成员 | 携带成员上下文进入授权工作区，清楚显示当前成员与资源角色 |
| 当前所属组织缺少明确展示 | 项目／组织顶栏只显示账号名与管理空间，难以判断组织归属 | 展示服务端授权范围内的组织信息，项目与任务组继续显式标识 |
| 从任务跳到监控后难以回到原任务 | 跨页仅保留任务组范围，原任务和列表位置容易丢失 | 保留受项目／账号约束的任务来源，提供返回任务入口，不缓存跨账号内容 |
| 快速切页时旧响应覆盖新内容 | 延迟旧项目请求、先完成新项目请求的真实页面处理器测试已复现组织与项目摘要回退 | 页面读取加入代次与会话边界，旧状态、配置和详情结果不得覆盖新页面；不取消已经提交的服务端操作 |
| 节点在线统计与健康接口不一致 | 预览实际 HTTP 响应中健康接口在线为 0，但项目 `fleet.online` 为 1；心跳扫描关闭时旧 `online` 状态没有刷新 | 项目、系统在线统计与组织节点健康展示统一复用已有心跳健康判据，不在读取时修改节点状态 |

## 实施约束

- 不新增人工执行阶段，不改变总控自动调度、模型决策、MCP 集中部署或按任务同步 Skill。
- 不因界面入口增加而扩大权限；显示与操作仍基于服务器的项目、任务组、账号能力判定。
- 公共对象导航与摘要提取到独立界面模块，避免新增成片的主文件模板。
- 完整信息放在对应对象详情或独立栏目，不通过删除功能和证据来缩短页面。
- 真实用户正在使用的预览页不作破坏性测试；交互验收使用隔离测试运行态。

## 实现结果

- `object-workspace.js` 集中渲染对象链接、层级路径与项目摘要。项目、成员和任务组的进入操作带明确资源 ID 与目标栏目，不再依赖说明页上的菜单卡片。
- 项目概况删除重复进度面板和七张菜单卡片，保留单份进度／状态／阶段／健康度摘要、关键指标和任务组明细；配置仓库数与产出目标条数分开，节点数字直接使用服务端项目范围统计。
- 组织成员可按人进入授权工作区，选择项目后分别分配项目角色与任务组角色。只预选被明确点击的合法候选成员，角色仍停在必选的空占位项；项目内部授权使用隐藏资源 ID 和可读项目名。
- 任务进入监控、审核、指令后保留受账号、项目、任务组约束的返回来源，返回任务后再回列表可以恢复原分页位置。跨项目或会话重置会清空来源。
- 页面读取采用代次与会话检查；状态缓存、配置、任务组详情及指令列表的旧结果不再覆盖新页面，当前真实请求错误仍可见。写请求的服务端处理不受影响。
- 窄屏下账号姓名与身份单独换行，避免身份徽标被截断；长层级名称自动换行，表格保留各自的横向滚动边界。
- 节点统计不再将心跳超时但尚未被扫描改成离线的节点算作在线；项目范围、系统范围和组织节点健康使用与健康接口相同的判定，原始节点生命周期记录不被读取请求修改。

## 复验记录

1. 隔离运行态：通过备份校验工具从已有测试预览创建 `.runtime/operator-clarity-20260905`，在 `127.0.0.1:4318` 验证。未在用户正在使用的 4317 页面中执行创建、授权或放弃草稿操作。
2. 浏览器管理员路径：服务端建立隔离组织后，以组织管理员在浏览器创建项目、暂停任务组和任务；从项目概况直接进入任务创建，从任务详情到监控、审核和指令再返回；从组织成员行进入定向授权，完成项目观察者与任务组观察者授权。
3. 浏览器只读路径：独立成员登录只见自己的组织和项目，概况不显示创建按钮；可从任务组行进入任务详情、监控并返回，不能启动暂停任务组。
4. 草稿保护：在项目规则中输入草稿，点击同项目的概况链接会确认；取消后文本完整保留，明确放弃后才切换。
5. 桌面与 390 × 844 窄屏：项目概况和任务详情无页面横向溢出；层级路径各元素的实际边界无重叠；姓名与角色完整显示，浏览器无脚本错误。
6. 页面行为测试增至 653 条，包括成员候选预选而角色不预选、对象链接、摘要去重、任务返回范围与分页、跨账号来源拒绝，以及延迟状态／配置／指令响应的真实处理器回归。旧响应测试先复现失败，再由修复转绿。
